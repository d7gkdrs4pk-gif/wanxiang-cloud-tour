# 雾林试炼 F.1

独立森林幸存者样关。入口：`index.html`，公开试玩 https://wanxiang-cloud-tour.pages.dev/forest-sample/?v=f1 。竖屏优先；按手机实际CSS尺寸绘制，画布DPR最高2，不缩放桌面整页。

左侧摇杆移动；靠近敌人自动出剑，右侧可主动出剑、施放范围技能。拾取灵光升级，三选一；林间宝箱给一次额外选择。游戏计时54秒古木灵鹿出现，红色预警与实际伤害使用同一世界XY圆。击败首领结算，可直接重开。桌面WASD/方向键、空格出剑、Q范围技能。

F.1包含一个1536²森林场景、四方向男主持剑精灵、三类小怪和一个首领、两种攻击、六种成长选项、一次宝箱及胜败/暂停/重开。没有职业、装备、账号或联机系统。

角色为20张原创方向/动作关键帧：闲置、两个迈步、蓄势及挥击；运行时有步态循环、收势混合和实体脚锚注册。它不是完整骨骼动画或自由旋转3D角色。树石是独立深度排序实体，碰撞只在树根/石脚，近冠局部渐隐；地图不包含角色或树冠贴图。场景与字体按正常手机画面验收，未以角色近照替代整屏。

## 素材与代码

代码为本次独立编写，无npm/CDN/第三方游戏运行库依赖。地面、角色、敌人与树石为本次ImageGen生成的原创素材；原生PNG、运行WebP、脚锚/裁框元数据、生成记录与技术打包脚本在assets/各目录。参考视频2的RO Survivors仅用于判断玩法/画面组织，没有导入其源码、角色、地图、技能图片、音效或音乐。原项目的制作/权利说明：https://ro-survivors.com/credits.html 与 https://ro-survivors.com/legal.html 。

运行时依赖的文件及SHA256见runtime-manifest.json。参考原视频及私人截图不在此目录或公开站点。保留原凤鸣H36、H31、H29及Cinderwatch入口，未改它们的游戏文件。

## 渲染与输入

Canvas2D原生绘制。原图不变；加载时缓存低alpha去噪、目标DPR尺寸及脚影stamp，以减少每帧重复缩放。树冠、树干仍分别绘制，没有烘平前后关系。原生Pointer Events支持多点触控；指针取消/失焦清理摇杆。加载失败可实际点击重试，暂停/隐藏页面不会继续战斗。

普通剑招：0–.15秒蓄势，.15–.34秒挥斩，.22秒判定命中，.34–.56秒收势。灵息范围伤害与8秒冷却可通过游戏数据检查。低帧率有最高.15秒补步，内部每1/60秒细分；编码录像帧率不作为游戏帧率。

实际测试数据、手机整屏、连续原速录屏见evidence/及QA.md。云端触屏模拟与真实iPhone/微信真机明确分开；本轮没有物理iPhone或微信真机。
