# 珠屿 · 镶金贝壳3D素材实验 V0.1

日期：2026-11-27。状态：单款模型生成及本机实渲验证完成，视觉未通过替换验收，未接入线上游戏。仅借用现有 GitHub Actions 与 Tripo 凭据执行，与凤鸣游戏资产及玩法无关。

## 当前成果
- `shell.glb`：API返回的原始带纹理3D模型，未改网格或贴图。
- `request.json`、`task.json`、`metadata.json`：请求、任务与来源记录。
- `renderer.py`：本机 Blender 4.3.2、Cycles CPU 64 samples 渲染脚本，六个方向；未修改模型材质。示例：`blender -b -t 2 --python-exit-code 1 --python renderer.py -- --input shell.glb --samples 64`。
- `render-qa.json`：几何/贴图/渲染检查。11566三角面，3张4096×4096贴图，原GLB 7190360字节。
- `shell-candidate.webp`：由真实模型渲染的透明候选切图，未用于生产。
- `review-sheet.webp`：原游戏贝壳与新模型的对照、32/48/72px同等占位模拟。不是已上线画面。
- `index.html`：旋转查看原GLB的浏览器预览。需联网加载固定版本的model-viewer；不同浏览器光照与离线实渲存在差异。

## 验收结果
- 模型格式/长度/SHA256验证通过，六方向渲染通过；几何与材质存在，原模型字节未变。
- 扇形、棱线、厚度和可见挂孔基本成立；未进行制造级拓扑/连通性检验。
- 金边粗细和挂环连接细节仍不够精致；缺少旧素材的金色分瓣装饰。
- 贝壳偏瓷白、镜面高光偏强，粉紫浅金珠光不足。当前候选不能判定比旧素材更漂亮。
- 三张4K贴图的母版不直接进入小游戏。当前透明WebP约18KB，仅证明可预渲染减重，不代表已完成游戏接入或手机验收。

## 消耗与边界
本次只生成1次，API记录消耗30 Tripo积分；未自动重试，未生成其他素材。既有游戏版本、存档、素材ID、价格、界面和经济系统未变。

## 下一步
优先基于现有模型调整珠光材质与金边细节、统一观察角度，再做实际小尺寸对照。达到优于旧素材的标准后，才替换单款并检查制作台/柜台/作品导出，暂不批量生成或全量3D改造。
