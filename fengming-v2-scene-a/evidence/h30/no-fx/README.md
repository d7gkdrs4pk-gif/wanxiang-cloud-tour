设备：云端Linux Chromium156，390×844触屏模拟。入口 `sample-gate.html?fx=0`。FOV39与原offset(6,27,15)未改，人物保持1.485原尺度。

命中事件发生在本次第一个达到0.44阈值的模拟子步，实际进度0.487564；该子步实体剑刃射线与敌人世界包围盒（扩展0.06单位）相交，命中头肩上沿；不是远处空放扣血。伤害值3→2，同一步触发敌人骨骼受击动作。抬剑图HP仍3，命中后图HP2，恢复后attack=null。所有图fxEnabled=false、trailVisible=false、moteCount=0，浏览器错误0。

当前正常画幅中抬臂与实体剑从一侧伸出、扫向敌人、随势回收可以区分，无需发光弧线代替动作。角色本体没有emissive；敌人原有冷青眼缝是常驻极弱材质，不是本次命中特效。最终连续动作与性能仍以主代理正常走位录像为准。

`data.json`保存最终逐阶段坐标、剑根/剑尖、敌HP、事件与帧记录。`first-render-frame-data.json`为初轮渲染帧末暂停的旧记录，其阶段有过冲，已隔离，不能据文件名当作精确阶段。
