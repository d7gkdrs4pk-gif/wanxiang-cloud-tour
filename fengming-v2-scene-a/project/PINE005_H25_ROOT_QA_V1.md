## 4. 版本与技术止损

本轮虽然解决了“是否存在破损网格”的疑问，并实质改变了根形，但二次修订仍存在显著“套筒拼接”视觉问题。**不能继续把简单根管生成 + Voxel 合并 + 轻微位移视为高保真雕塑的替代。**

- **唯一正式资产母版保持 H.23**：`assets/pine-005/h23/pine005-h23-refined.blend`；H.24 和 H.25 均视为可回顾但未经美术认可的独立实验。
- 下一任务不再默认重复这一类自动融合模型；应把 G1-A 高保真古松根部作为独立小样，采用真正可控、能与原图局部形状对应的专业 Blender 雕刻/拓扑工具先证明质量，或评估具备有机植物制作能力的专业流程。高质量小样通过后再编辑当前正式资产。
- **不进入 G1-B 树冠、G2 PBR 贴图、iPhone 多株性能与正式游戏集成。**
- 效率止损：本轮已尝试两次受控生成且核心视觉缺陷仍未消除，应暂停相同算法的继续微调，不再盲抽付费模型。
