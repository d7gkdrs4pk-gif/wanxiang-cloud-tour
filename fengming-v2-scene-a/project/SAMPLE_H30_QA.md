## 实现

林砚沿用项目男性红金持剑设定。新制实时转身的 22 骨/3037 三角骨骼角色及独立长剑，头发、肩背、手臂、外衣摆分开塑形；待机呼吸、步行、转身衣发惯性、右侧蓄势→前斩→左随势→收剑完整动作。高度 1.485，对照占位人物约 1.47，未靠放大角色改变比较。影煞为新制 19 骨/1866 三角哨兵，3点生命。

地面与屋檐复用现有 3D 资产，降低白砖亮度/纹理对比，静态方向受光与脚影同向。两层远山和薄雾承接岩壁后的空处；地面、屋檐、真实台阶、人物均未压成一张背景。静态场景用低成本材质，角色保留实时立体受光。灯光少量暖色，无树脚橙色强光斑。

迎客松按已批准参考新制三层树图，后冠、树干和前枝分开深度测试。树根位置及 .72 碰撞不变。针叶形成最大横冠、较小顶冠与错开的后冠；层间留缺口。正常游戏镜头下，进入前枝遮住头肩局部，身体/道路仍清楚，走出后露全；不是整树透明。定点像素测试在进入/离开各为826角色像素，枝下736，局部遮90像素（10.90%），见 `evidence/h30/occlusion-final.json`。

复用 H.29 的 pointer 触控、4.5 移速、相机跟随、原地形栅格/flood fill、桥连接/高度插值、.9 高差检查、轴向碰撞回退及攻击距离/伤害/冷却。靠近目的地时按剩余距离收步，修正旧实现先normalize再取length导致的越步。低帧率按真实经过时间分成≤.05秒子步（最多补.20秒），保留碰撞步长，防止整段走路/动作变慢。一屏边界阻挡出屏，远处8块地图不重复渲染；原完整工程仍在原入口。原版 gate 只有视觉模型，新增仅针对右侧四个真实低台阶的地面采样，未让人物踩屋顶。高度实测约 .274/.398/.520/.692/.714。树旁原 .5 栅格的假孔只在一小块区域按原高精度地面加 .05 细采样，保留真实根碰撞与岩壁阻挡。细采样四邻缺值会先取最近有效点，再回原导航。原 H/R/step 数据与新缓存可字节级重建，凭证见 `assets/sample-lod/navigation-rebuild-proof.json` 与 `pine-patch-validation.json`。

普通剑招时长 .78 秒，.44进度过命中姿态后扣1生命、同帧启动敌人受击，范围沿用2.6。剑光只在剑锋外半段短暂出现，普通命中10个小粒子，觉醒40个更大粒子；无光效仍有完整实体抬手、斩击与收势。受击火花取实体剑段上最近点。不是自动范围光圈替代剑动作。无特效独立测试的实体剑段与敌人世界包围盒（.06容差）实际相交；测试使用背向敌人的石阶站位，真实按键转身出剑，敌生命3→2，命中进度.487564（首个跨.44的子步），错误0。

## 运行证据

本次完整连续实走成功：走近古松→穿前枝→离开→绕门前→登四级侧阶→回身挥剑→实体命中影煞→收势。最终脚下高度 **0.715349**，敌生命 **3→2**，四项路线标记均为true；运行错误0、失败请求0。视频 **14.76秒**，原速、没有插帧。实测147个渲染帧覆盖13.9912秒，平均 **10.435 FPS**，中位帧间隔89.30ms，P95为176.90ms；视频容器25FPS只含重复持帧，不代表游戏帧率。命中事件进度 **.448718**，该子步已更新实体剑姿态并同步受击。见 `evidence/h30/sample-walk-sword.mp4`。

最终记录以 `evidence/h30/sample-playtest.json`、`sample-video.json` 和 `video-probe.json` 为准。连续录屏使用可信浏览器触屏输入；没有注入角色位置、相机或自动走路脚本。相机 FOV39、追随偏移 (6,27,15)，画幅390×844；视频原速、无插帧，隐藏调试、保留操作UI。

单独的楼梯/遮挡/无特效定点试验允许测试夹具设置初始站位，仅用于量化和姿态取帧，与连续操作录像区分。H.29 同机位对照也只改初始站位/朝向、使用同版本本地引擎，不改原模型、材质、动作或游戏数值；原正式入口文件 Git blob 仍 `82e9ce953fc1954c7408ebbc835dbab37098aa64`。

运行环境：云端 Linux x86_64 / Chromium156 / ANGLE SwiftShader 软件渲染，手机尺寸触屏模拟。不是实际 iPhone Safari，也不是微信真机或微信开发者工具预览。实测FPS为 render完成时刻计算的游戏帧率，视频容器25FPS不是游戏FPS。未据此声称手机硬件流畅度通过；iPhone可直接打开HTTPS样版亲手复核。
