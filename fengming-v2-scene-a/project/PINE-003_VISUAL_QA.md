## 2. G1–G4 分层验收

| Gate | 实际判定 | 证据与理由 |
| --- | --- | --- |
| **G1｜剪影/结构** | **不通过** | 主干虽然已具弯曲与较粗根部，但视觉上仍以垂直小盆景为主；枝冠按平行水平带状均匀排布，缺少参考图中非对称、强风姿、错层伸展及复杂自然分叉；黑色剪影与原图明显不一致。 |
| **G2｜美术/材质** | **不通过** | 相比 PINE-002，空心叶团已消失且叶色趋于深松绿；但针束仍像均匀的尖刺/草丛，枝条太直、老树皮光滑、盘根抓岩不足，未达到批准参考图的写实质量。侧面树冠纵深改善但依旧欠厚重。 |
| G3｜iPhone 性能 | 待真实设备验收 | Chromium 桌面与模拟手机视口加载和按钮检查通过、控制台 0 错误；软件 GPU 渲染数字不代表 iPhone。未测真实设备的 1 株/8 株 FPS、内存、加载时间。 |
| G4｜游戏集成/通行 | 未启动 | G1/G2 未通过，禁止合入游戏；正式场景仍保持 V2.0 H.17.2。 |

## 3. 有效成果

1. 原型将树干、主枝、叶冠、根石拆成可独立调整模块，后续更换其中一类不必重做全部。
2. 验证以生成式代码制作实心针叶云片可以避免 PINE-002 的“甜甜圈”几何缺陷，但程序化并不自动保证自然写实。
3. 图形结构：13,110 个针叶实例、19 组冠片、8 组主枝；体积边界约 10.73 × 8.02 × 4.29 预览单位（非米）。
4. 正面/侧面/背面/俯视、黑色剪影与针叶密度交互均可用于后续模型验收；Cloudflare 已部署，不额外租用服务器。
5. Tripo 新增消耗 **0 credits**；本轮不修改已确认的历史成本口径。

## 4. 止损与下一任务

**不再将 PINE-003 的参数化建模简单加针、加粗或调色视为写实修复。** 继续这样做容易提高消耗但不能达成原图级的真实形体。该模型可保留为远景或低精度树木技术样本，但**不用于古松主要场景**。

**下一轮主目标（H.19.2）**：优先核实可用于游戏的高品质松树 3D 资产/可编辑源工程（明确许可），或者可基于参考图精确调整的 Blender 建模流程；重点验证粗壮 S 形主干、真实细枝、针叶云片和根系的正面轮廓。独立样件必须通过 G1/G2 才可评估导入。对高风险/费钱路线，在有多角度真实对照和明确成本前，不调用 Tripo 二次付费。
