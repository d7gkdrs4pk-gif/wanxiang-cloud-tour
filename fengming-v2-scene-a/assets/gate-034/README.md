# H.34：让出交战视窗的单檐山门

运行中的实际资产由 `sample/gate-roof-finish.js` 创建：真实静态 3D 瓦面、木构、门匾、石台与逐级石阶。H.33 三座高大屋面已替换为一座较低、较窄的门楼；没有把山门压成背景图，也没有改变 FOV39、跟随偏移 `(6,27,15)` 或人物比例。

## 正常镜头下的设计

单檐中心约为 `(-.81, -7.60)`，屋面宽 2.48、进深 4.00 个原世界单位，檐口 Y=3.05、含小脊饰最高约 Y=4.547。东檐收进、南前缘后退，西檐避开古松前枝；原右阶与影煞交战区留在屋面之外。南向前柱间有完整厚木门楣和内卷拱托，“凤鸣”厚匾朝 +Z 面向正常镜头，字随世界 X 向右排列，保持正立。没有新增第二层大屋面或金球装饰。

原扫描模型的破碎低层仅在渲染中隐藏；它的原属性、有序索引和源文件完整保留，可由 `restore()` 还原。新可见部分为干净低石台、柱脚、少量短石栏、抱鼓石及原右阶位置的真实踏面。平台内侧原不可走区域不放开，原碰撞与导航不改。

共 **17,402 三角、4 材质／draw**，低于 H.33 新增部分的 24,030 三角。柱、梁、筒瓦曲面、搭接、厚檐、门牌和台阶立面都属于实时 3D 网格。

## 原碰撞的可见边界

最后一项修补只增加468三角：东侧北部已有原高岩，不设额外栏杆。南边低石栏中心 Z=-3.86、东边中心 X=2.24，约内缩原禁行框0.21；原东阶在 Z∈[-7.55,-6.75] 留口，比合法缓存范围两侧各宽0.15。西侧前端短返边连接原平台，阶顶西内侧放一段短低栏表示内院暂未开放。低边沿原地形落脚，可见高度约.3875；门前 Z=-3.05 和东侧 X=3.1 原路线不被侵占。没有新增高墙、改碰撞或扩大不可走点。`boundary-data.js` 保存原地形采样，`boundary-qa.json` 记录内缩、路线净距与最终整屏结果。

## 实际入口和资源屏障

主入口在 `env.styleGate(gate)` 之后、`prepareRoof(gate)` 与遮挡 BVH 之前调用并等待：

```js
const finish = finishGateRoof(gate, {
  shading: params.get('roofPbr') === '1' ? 'pbr' : 'light',
  stoneTexture: getEnvironmentStoneTexture()
});
await finish.ready;
```

正常入口为 `light`：瓦面、木构、少量旧铜与字牌用 `MeshLambertMaterial`，继续接收原主光 `(-8,16,12)`。石材共享场景已载入的 `assets/environment-033/handpainted-stone-atlas.webp`；固定主光、色温和屋面投影阴影烘入石面顶点色，静态 3D 石材用 Basic 表达这次固定受光，避免重复纹理和昂贵实时阴影。不是给整座门楼使用无光背景板。全部近景材质 `fog=false`。

字牌与旧铜共用本目录 9.5KB 的 `plaque-atlas.png`。`ready` 等待其 `loadAsync` 成功后配置 SRGB 与材质；失败会带资源路径拒绝并进入主入口的重试流程。实例在图片加载中被 `restore()` 后，迟到的独占纹理会释放；共享石材不被组件释放。

`?roofPbr=1` 保留材质对照；底层模块不传 shading 时默认 PBR，主入口显式选择 light。`?roofFinish=0` 可恢复原来源模型对照。源文件 `assets/sample-lod/gate.glb`、原地形与导航不写入。

## 台阶与视线数据

- `steps-data.js` 由原 `navigation.json.steps` 直接生成，保留 850 个有效缓存格。每个 2.5cm 格有水平踏面，邻格高差有真实立面，匹配原 `stairsAt()` 最近邻判定；没有改成斜坡。
- `step-height-qa.json`：4,048 个原中心及格内稠密射线点，最大高度误差 **1.5473e-7 原世界单位**，缺面0。记录包含全部850个原中心。仅为抵消 Float32 坐标反变换，在外边界增加2微米守护量，不改变导航边界。
- `geometry-qa.json`：原 21,403 个低层三角的属性／索引逐值一致，原 GLB／缓存 SHA 保留；17,227 个 XY 网格点的 `safeGround` 合法性和高度前后完全相同；还检查有限数值和 restore。
- `visibility-cpu.json`：实际 H.34 男主的101个攻击阶段、4个阶侧站位，胸、头、剑根、剑尖和敌胸共2,020条精确三角射线，遮挡0。此项不依赖透明 shader，不等于完整动态游戏验收。
- `plaque-direction-qa.json`：南面 +Z，UV 的 U 随世界 X、V 随世界 Y 增长，字形正向；`ready-interface-qa.json` 另测成功、失败、提前销毁后的异步资源归属。

原始高程来自现有缓存，天然含轻微扫描高差。密集校验避开最近邻跳变的恰好半格边界，并保留每一个原缓存中心；没有用平均值掩盖逐阶差异。

## 可编辑源资产与复作

- `source/gate-h34.blend`：可编辑四批真实网格，两个贴图已打包，附原镜头参数的参考相机。参考灯光仅供母版编辑，不替代实机截图。
- `source/gate-h34.glb`：同一可见网格的 Y-up 世界坐标母版，内嵌字牌 PNG 与石材 WebP。标准 GLB 使用哑光 PBR 表达运行时的 Lambert、并给静态石材保留 unlit 顶点受光；因此母版通用查看器的色调不能当成游戏最终调色验收。

两份母版为审阅和复作源资产，**不被试玩入口请求下载**。`.blend1` 自动备份不放生产资源目录。复作命令在项目目录执行：

```sh
node tools/build-gate-034.mjs
blender --background --factory-startup --python tools/build-gate-034-blend.py
```

第一条生成高度数据、CPU记录与 GLB；第二条导入、打包纹理并保存可编辑母版，不渲染、不占游戏 GPU。可用 `FENGMING_GATE_MASTER_DIR` 指向其他母版输出目录。

几何、材质编排、动画外的建筑脚本均为本项目原创；石材复用本项目手绘资源，来源见 `assets/environment-033/`。字牌使用本机 Noto Serif CJK SC 字体栅格化，保留 OFL-1.1 全文及字库／图集 SHA 于 `OFL-Noto-CJK.txt`、`font-source.json`；未分发字体二进制。未从 Frog Ferry、Slackwater 或其他游戏复制模型、纹理或门楼截图。

本模块未量测最终游戏 FPS，也没有执行 iPhone 或微信真机测试。最终连续触控、同位版本对比、实际帧率和新版入口以主任务的最终记录为准；运行成功不自动代表用户美术验收通过。
