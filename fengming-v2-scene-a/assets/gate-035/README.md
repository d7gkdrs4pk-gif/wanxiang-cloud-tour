# H.35 白天石作山门

本轮把 H.34 的平整门台表面改成真实厚石板、分段台沿和倒角柱石，并用一条连续苔岩裙台把山门接回山坡。原屋檐轮廓、柱位、松檐空隙、FOV39／跟随偏移 `(6,27,15)`、角色尺寸与通行路线保留。H.34 的 `assets/gate-034/` 未写入，仍供旧版对照。

## 真正加载的 3D 内容

`sample/gate-roof-finish.js` 是实时构造模块，加载本目录数据并创建实际静态 3D 网格：

- 22 块错缝切角厚石板，24 段倒角台沿石，四个倒角柱石座，八块踏步外侧石帮。台面暗缝凹入；内芯向内退 4cm，让侧石体积直接露出。
- 一条 78 三角的连续苔岩裙台，前缘 Z=-3.94、后缘 Z=-5.27；前部设计 Y=.17、后接 Y=.645，右端贴随原有高坡。非平行中间折线、独立顶面平滑法线和 4.8m 的固定 XZ 岩纹取样使其读为一体岩台。它完全处在原禁行范围内，没有新铺可走台面、加墙或堆独立大石。
- 柱石与柱脚接合，柱梁节点及檐下有局部接触暗部。原低栏位置、高度和阶口保持，没有重新增加高地北侧栏。

总计 **18,416 三角、4 材质／draw**，较 H.34 的17,402三角增加1,014，未增加材质批次或实时阴影 pass。屋檐／木构／旧铜与字牌使用受光轻材质；新石作用同一个共享石材纹理和固定日光顶点色。

## 同一套石材和日光

石材直接复用 `getEnvironmentStoneTexture()` 返回的稳定 Texture，即 `assets/environment-035/stone-kit-atlas.webp`。它是项目既有石材画布的版本化复用。厚石块每面只取左格石面内部四块安静区域，不把画布里的旧接缝再次贴到实体缝上；岩裙台取右格单块岩体内部，X/Z 使用一致4.8m尺度。

石材保持廉价的 Basic + 顶点受光：归一化 SUN `(-8,16,12)`，冷暗 `(.36,.46,.57)` 至暖亮 `(1.15,1.14,1.08)`，与新3D石路使用同一基准。块间只做很小的颜色变化，柱脚／遮阴由同方向局部暗部承接，没有通过全场降亮、发光或新增火把制造体积。

主入口仍在 `env.styleGate()` 后、`prepareRoof()`／BVH前调用，并显式选择 `light`，传同一 `stoneTexture` 后等待 `result.ready`。字牌纹理只从构造模块的 `new URL('../assets/gate-035/plaque-atlas.png', import.meta.url)` 解析，符合源页面和classic bundle的资源契约。`ready` 覆盖图集成功／失败／提前释放，石材不重复下载或释放共享 GPU 纹理。

## 原有高度和路线

原 `navigation.json`、地形高度缓存与碰撞逻辑不写入。可行走踏面仍严格按原850个有效最近邻格生成，外侧石帮在合法阶面Z范围之外。

`step-height-qa.json` 保留4,048个稠密高度采样，最大误差约1.55e-7原世界单位、缺面0；`geometry-qa.json` 记录原21,403低层源三角属性／索引精确保留，17,227个合法点与高度前后不变，以及当前生成几何和材质数据。原扫描低层只在渲染隐藏，可由 `restore()` 还原。

`visibility-cpu.json` 由实际 `sample/hero.js` 和 `assets/hero-035/action.js` 生成，记录两个文件SHA。它采原四个路线位置和当前真实脚高，跟踪实际胸／头骨与实体剑根、剑尖，主套2,020条，另补敌人出生位2,020条；不用透明cut shader。最终实际runtime（hero `6a77d824…0e0e`、action `60253078…8836`）无override复核：主套0/2,020、总计0/4,040遮挡，四个源码SHA与当前文件相同。不能将H.34旧动作的零遮挡数字当成H.35结论，也不能用该组件CPU检查替代整场连续操作录像。

## 复作源资产与记录

`source/gate-h35.glb` 与 `source/gate-h35.blend` 为同源可编辑模型，四批真实网格、两个图集。母版不被试玩入口额外请求；实际游戏直接使用上面的静态构造模块。GLB用标准哑光PBR表达Lambert部分，石材保留unlit顶点受光；通用查看器的调色不替代游戏原镜头验收。Blend图集已打包，自动`.blend1`不放生产目录。

```sh
node tools/build-gate-035.mjs
blender --background --factory-startup --python tools/build-gate-035-blend.py
python tools/check-gate-035-master.py
node tools/check-gate-035-visibility.mjs
```

前两条生成同源母版和高度／路线记录，不执行GPU渲染；第三条检查GLB缓冲、嵌入图集及法线；第四条使用当前H.35动作做完整视线检查。离线腕轨候选可用 `--action-file`，只重测上次失败点可用 `--failed-only`，候选输出保留QA目录，不覆盖实际runtime的完整报告。

几何、拼装、顶点受光与新增岩台代码为本项目原创；石材来源沿用项目已有画布，见 `assets/environment-033/` 与 `environment-035/` 的来源记录。字牌像素原样复用H.34的本机Noto Serif CJK SC栅格化结果，OFL-1.1及图集／字体SHA保留于 `OFL-Noto-CJK.txt`、`font-source.json`，没有分发字体二进制。

正常手机画幅第三稿已由主流程检查台基接地、石作厚度、场地连接及人物／敌人可读性；最终整场触控、实际FPS与试玩入口由主任务统一记录。组件没有运行iPhone或微信真机，也没有把母版图、停帧或编码FPS当成真机性能／用户美术验收。
