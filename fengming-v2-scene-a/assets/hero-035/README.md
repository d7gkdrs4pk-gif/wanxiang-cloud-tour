# 林砚 H35：承重、踏步与低位收剑

本目录仅更新动作，复用 `../hero-034/` 的真实网格、1K图集、22骨和原 bind；没有重出一份相同大网格，也未覆盖 H34 的对照资源。运行仍由 `sample/hero.js` 返回原API，普通攻击周期 `.78s`、伤害 `.44`，独立剑始终挂右手，外层人物 position/scale 与碰撞不变。

## 动作改动

- 蓄势把重量移向右后足，左前足抬起并内收；前足在`.34`落稳后再到`.44`命中。原阶面很窄，前踏由最初13cm减至5.5cm，避免把足心跨到低阶后悬空。
- 髋、脊柱、胸及副手分别推进：髋先从后负重转向前支撑，胸肩随后完成斩击；衣摆与发束稍后跟随，收势再错相回稳。
- 腿用现有骨架的双段解保持鞋底平放；只在足踝内部校正鞋底余量。后足跨略高的旧阶棱，因此右靴有约1.4cm额外局部支撑余量，未抬人物group、髋或导航地面。
- `.62→1` 先把持剑手撤向身体外侧/右腰后；最终腕轨在`.70/.72`短暂立尖，让刀转到外侧后落回护位，再接原待机。该段绕开低栏/台沿，不经敌人前向倒擦；只有15个腕key变化，承重/足底和`.44`保持。
- 手腕轨道通过离线工具重新记录为本地 quaternion；运行时不追踪世界目标，固定剑 socket 不变。`.44`仍需用真实刀段与低台阶敌头部相交验证。

## 可编辑动作源

`action.js` 明确记录髋、胸、双臂、双足、衣摆、头部与本地腕轨；普通身体通道使用连续Hermite曲线，足点有落地保持区，腕轨用51个本地 quaternion 关键点。

`linyan-h35-animation.blend` 为动画母版：本地可编辑22骨与 Idle / Walk / Slash，4个网格的数据通过相对库路径 `//../hero-034/linyan-h34.blend` 链接旧母版。默认打开Slash `.44`接触姿态；旧034源不变。

```sh
node .github/scripts/hero035-build-action.mjs
node .github/scripts/hero035-export-samples.mjs
blender -b --python .github/scripts/hero035-animation-mother.py
node .github/scripts/hero035-measure-poses.mjs
```

`source/pose-samples.json` 保存骨世界矩阵、原bind和真实socket；`source/wrist-authoring.json` 保存离线腕轨来源；`source/normal-pose-deltas.json` 用同一FOV39/390×844/跟随偏移(6,27,15)记录H34与H35骨投影差。接触时髋为 `[+.02,.655,+.035]`，髋yaw `+.20`、胸yaw `-.32`；相对H34同相位，踝投影变化约3–5px，实际踏步/承重不靠改相机。

## CPU验证与实际画面边界

独立CPU检查固定socket、group不移动、全身起收连续、7.8/12/30/60FPS步进后回idle无残余姿态、`.44`真实头部接触与收势无再次穿体。1001动作相位的实际鞋底不穿人物局部支撑面；360组真实阶面（站位x1.55–1.66、z约-7、朝向1.05–1.15，静置/接触）无穿阶、无整脚悬空，最小余量约1.02mm。脚尖伸出低一阶的上方是局部悬边，不能把其最大间隙误判成整脚不接地。

完整静态门楼4040条真实三角射线（两个敌位、四个原路线站位、101相位、五个视线点）最终0遮挡；低阶和同地面敌人完整`.620～.999`各380采样仍0再次穿体。该结果不代替正常原速录屏对短暂立尖和收剑节奏的判断。

动画母版逐样本回放骨矩阵最大误差小于 `6e-7`；仅约230KB，新母版没有复制身体网格。最终动作仍需在正常镜头关闭FX走测；CPU数据或近距骨骼图不能替代动作可读性的美术判断。
