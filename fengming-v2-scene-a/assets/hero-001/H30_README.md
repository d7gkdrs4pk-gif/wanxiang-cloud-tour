# 林砚：样关轻量3D男主

当前源文件：`../../sample/hero.js`。本轮自制的程序化几何、骨架与动作，直接在Three.js中生成，不依赖第三方角色包、外部纹理、付费模型或远程动画。

设定依据为本工程 `project/GAME_DESIGN.md`：**男性铃师林砚，红金服饰，悬铃凤刃**。未改成女性。造型采用自然肤色的角面男性头部、束发冠/长发尾/发带、肩背短披、分叉长袍、内衫与靴、腰铃及独立剑。总高1.485，保持H.29原占位人物头顶1.47的尺度；未通过放大角色制造可读性。

资源预算：3037三角，7材质，22骨骼。主体为一个分材质SkinnedMesh，长剑是右腕骨下独立Group，剑刃、护手与缠柄为实体几何。无发光或透明材质。材质使用自有顶点色；阴影由场景控制。

## 接入

```js
import {createHero} from './sample/hero.js';
const hero=createHero();
player.add(hero.group); // 本地+Z为前方，沿用player.rotation.y朝向
hero.update(dt,{
  moving: moving,
  speed: worldSpeed,
  attackProgress: attackActive ? attackTime/hero.attackDuration : null
});
```

`update` 不移动人物、改变游戏相机或自行触发伤害，只负责待机呼吸、迈腿、肩袖/衣摆摆动、转身惯性和完整挥剑姿势。未提供`turn`时自动从角色世界朝向计算；也可以传归一化-1..1的转身强度。`attackProgress`为null/负数或>=1时回到普通状态。

建议攻击周期 **0.78秒**，伤害判定在归一化 **0.44**：右侧抬剑预备→扫过角色前方→左侧随势→收剑。首尾实际剑锋方向对齐待机，不把命中帧做成静止竖剑防御。攻击数据由现有战斗系统控制；需要在单帧跨过0.44时仅调用一次伤害判定。

- `hero.swordTipWorld(out?)`：实体剑尖世界位置。
- `hero.bladeBaseWorld(out?)`：剑刃根部世界位置。
- `hero.sword`：独立剑Group，用于挂剑光或检查。
- `hero.stats`：几何预算和动作时序。

剑光应该依据实际剑刃根部/剑尖的轨迹产生，不能用与手和剑无关的固定圆环代替。关闭剑光时仍保留真实手臂抬起、出剑侧、实体剑轨迹与收势。

## 复核

本轮使用Chromium、FOV39、原相机偏移(6,27,15)、390×844视口做无特效角色检查，并逐阶段检查0/.14/.28/.44/.61/.82/1攻击姿势。源码JS语法和浏览器无运行错误。最终美术判断仍以集成样关的正常游戏镜头为准，不以近景检查图冒充手机效果。
