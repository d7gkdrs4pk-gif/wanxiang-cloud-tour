# H.33：厚檐与受击轮廓

本轮沿用 H.32 的三层曲面山门，仅修改 `sample/gate-roof-finish.js`、`sample/enemy.js` 和本目录。未修改正式 H.29 入口、原 GLB、地形、导航、相机、通行线、角色尺寸或伤害命中时刻。

## 屋檐实际修改

- 将高反差的离散浅色瓦替换为接近明度的冷青灰哑光瓦；每片仍为真实凸筒瓦及搭接唇。大面的低频旧色保留，去掉逐瓦随机亮斑和高频顶点碎色。
- 瓦下闭合实体厚度从 0.15m 增为 0.20m。独立深墨木底檐、厚弯曲檐带与细滴水边形成上表面／檐口／下阴影；顶层曲线和原三层轮廓保持，未增加阴影贴图、屏幕后处理或额外 draw。
- 四根新木柱下接现有石基，不再从任意 Y=1.2 截面开始。原源网格中心采样的左内基座约 Y=.154，右侧石坪约 Y=.71；新增八角石脚和深木柱鞋略微嵌入既有支持面。下部源三角没有删除、移动或重新拓扑，碰撞仍取现有导航。
- 缩小且收哑旧铜脊饰和柱箍，避免暖亮点抢过角色。木匾继续为本机字体生成的“凤鸣”，未引入外部图像。

实际入口仍在 `env.styleGate(gate)` 之后、`prepareRoof(gate)`／BVH 之前显式调用：

```js
finishGateRoof(gate, {
  shading: params.get('roofPbr') === '1' ? 'pbr' : 'light'
});
```

正常入口为受光 `light` 模式：瓦／木 `MeshLambertMaterial`，仅少量铜饰为 PBR；保留 H.32 已校准的线性材质倍率瓦 3.2、木 2.0，全部近建筑材质 `fog=false`。模块不传参时的 PBR 仅供单独对照，不代表入口默认。主光、环境光与场景曝光均未改。

原 33,000 三角中，所有最低世界顶点 Y≤1.2 的 **21,403 个三角**有序索引和全部属性缓冲逐值保留；原 GLB 和 `navigation.json` SHA256 未变。H.33 新上部在含系统木匾的 DOM 环境为 **24,030 三角／4 材质与 draw**，较 H.32 增加 1,968 三角，用于厚檐滴水与落地柱脚。总计 45,433 三角；三层顶面曲线、116 行各六片短筒瓦、整体世界范围仍在原包络内。新增下檐与石脚合入原三批几何，没有增加 draw。

## 敌人命中动作

影煞身高标称 1.46m、1,866 三角、2,501 顶点、19 骨、4 材质／draw 均保留；轮廓仍为靛布、灰石甲和冷铁短刃，未用男主朱红／金色。铁刃改为收哑旧铁。

接口仍为 `foe.hit(worldDirection)`，由现有普通攻击真实伤害帧调用；H.33 主逻辑保持攻击进度 .44 扣血。本模块只处理视觉，不改伤害范围、敌人 HP 或外层位置。世界冲量先转入敌人局部坐标，再做 .145m 的躯干退让；胸背和面甲后仰、左右膝错开压缩、一肩失守、手腕和短刃滞后甩动。

反应总长 .34s，命中当帧已有四分之一强度，.075s 达峰、保持到 .125s，再连续缓动回到原待机姿态。比旧版短峰值更能在低帧率时保留下来。靴底与双腿反旋，峰值时鞋底仍贴近原地面，未靠增加光效或粒子遮盖动作。可传 `hitProgress∈[0,1]` 做确定性检查；`stats.hitDuration`、`hitPeak`、`hitHoldUntil` 给出相同数据。

## 来源与验证边界

新增几何、材质颜色与动画为本项目原创代码。无第三方模型、动作、贴图或付费素材；“凤鸣”字使用本机 CJK 字体本地 canvas 渲染，不分发字体文件。Frog Ferry、Slackwater 的层次与运动可读性，以及 OpenGame jingyang 的动作节奏只作方向研究，未复制素材或移植 2D 逻辑。

本目录 `candidate-structure.json`、`cpu-verification.json` 记录保留面、实际使用索引世界范围、两种材质的相同几何缓冲及有限值检查。`enemy-reaction-cpu.json` 记录实际骨骼／蒙皮采样、方向转换、峰值和连续恢复。CPU 检查与代码可运行均不能替代正常手机画幅的美术判断。

正常整屏、走位与实际 FPS 以主任务的最终证据为准。云 Linux 软件图形栈的手机尺寸浏览器模拟不等于 iPhone 或微信真机，本模块不宣称已通过真机或用户美术验收。

工作树浏览器检查另见 `working-browser-check.json`：390×844 DPR1、Chromium156／SwiftShader，触控行至真实台阶 Y=.712526，一次普通攻击 HP3→2，错误0。未采计帧率；这组截图绘制延迟已越过受击峰值，不能作为峰值动作证据。检查还发现头部射线已通、躯干仍被前檐遮挡而 cut≈0，已交由主逻辑负责人补测躯干射线；因此该工作树画面没有被标为可交付美术验收通过。
