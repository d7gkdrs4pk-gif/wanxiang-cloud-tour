# 林砚 H33：固定玩法镜头下的侠客轮廓

本目录为本工程自制的男性铃师林砚，不含外部人物、动作片段或参考游戏图像。运行模块为 `../../sample/hero.js`，完整离线造型源为 `../../../.github/scripts/lib/linyan-h33-generator.mjs`。H31/H32 的原几何与生成源仍保留在 `../hero-001/` 和 `../../../.github/scripts/lib/linyan-h31-generator.mjs`。

## 改动针对正常手机画幅

H32 的主要问题是黑发贴红肩、持剑手与衣袖粘连、袍摆与双腿挤成一块。H33 先修改结构再处理颜色：

- 连续躯干上衣收腰、展开肩袖，弯肘将持剑手移到腰外，手与深袖口分开；没有叠肩球或拼积木护臂。
- 束髻向后扫，单束发尾离开肩背，额面和窄颈露出；不靠小眼眉纹理充当识别特征。
- 双片骑行袍前开口扩大、前后错长，深色内裤和双靴从衣摆下露出；褶皱保留几个大面，删除高频细折。
- 朱红主体、墨黑发、少量暖米色交领、窄旧金袖口和剑格，全部哑光。顶点色仅承担布料层次与腋下轻微自遮挡，不烘焙固定方向亮斑；主受光继续来自场景 SUN(-8,16,12)。
- 独立凤刃保留真实双面剑脊、针形剑尖与缠柄，扩大横向剑格的大形。

高度仍 1.485；22 骨及原 inverse bind、右手剑 socket、FOV39 与跟随偏移(6,27,15)保持。不得用拉近镜头、放大人物或独立近照替代正常画幅验收。

## 骨动画与命中

剑始终是 `rightWrist` 的子节点，局部 position/quaternion/scale 在完整剑招中固定。连续右侧起手→前扫→左侧随势→收势由本地骨姿态组成，手腕使用 51 个离线记录的本地 quaternion 关键点做 slerp，不在运行时覆盖武器世界方向。

全身攻击包络覆盖副手、腿、袍摆；脊柱俯仰是连续关键帧，消除了 H32 的 `.28` 瞬切。周期 `.78s`，命中阈值 `.44`，最终仅在 `.32~.56` 的手腕轨道中平顺收锋，`.44` 实体刀线穿过样关低台阶敌人的头部面罩；同地面时穿腰部/躯干，刀尖仍离地。没有把“剑轴接近角色前向”当作实际命中的替代条件。角色模块不负责导航、攻击范围、扣血或相机。

接口仍为 `createHero()` → `{group,body,sword,update,stats,attackDuration,hitProgress,swordTipWorld,bladeBaseWorld,getAttackProgress}`。

## 可复现资源流程

```sh
node .github/scripts/bake-linyan-h33.mjs
node .github/scripts/verify-linyan-h33.mjs /tmp/linyan-h33-verification.json
```

运行时只装配离线烘焙 TypedArray，保持 H32 的快速启动路径，不现场执行 SDF、曲面采样和法线计算。`manifest.json` 记录源 hash、每个实际数组与 bind 矩阵 hash；自有造型与烘焙输出逐字节核验，动画对齐验证另存测试记录。

当前实际几何：16,026 三角形（身体15,650，独立剑376）、9,210 身体顶点、22 骨、7 材质。资源 JS 1,007,321 字节，gzip338,816 字节。数字用于资源核对，不能当作美术合格的替代证据。

风格研究参考 Frog Ferry / Slackwater；动作组织仅参考 OpenGame 文档关于手骨挂剑、连续姿态过渡的方法。没有拷贝这些项目的模型、贴图、动作或控制器；来源记录见 `provenance.json` 与工程 H33 来源表。
