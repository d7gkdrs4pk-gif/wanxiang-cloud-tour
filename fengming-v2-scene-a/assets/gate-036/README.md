# H.36 山门可编辑 PBR 源模型

本目录是用于整套 Blender 场景验证和后续烘焙的源资产，尚未接入试玩运行时。模型、结构和新增石作为项目原创。未复制或公开本地私有参考。

`source/gate-h36.blend` 可追加 `H36_GATE` 集合；`source/gate-h36.glb` 是同源导出。两者均位于实际世界坐标。Three `(X,Y,Z)` 对应 Blender `(X,-Z,Y)`，没有相机、灯光或顶点受光。根场景负责统一真实日光、材质校准和烘焙。

新门楼采用东西向曲脊、实体厚檐、独立短节凹底瓦与半圆盖瓦。第二稿有210片底瓦、224片盖瓦、32个瓦当；真实搭口错高约3.4cm。屋檐包络仍为 X `[-2.108,1.258]`、Z `[-9.415,-5.785]`，最高 Y约4.571，未扩大到右阶交战区。柱梁、曲线雀替、半开门、低砌石墙和深木上壁为实际几何；六个柱脚由两层倒角青灰石座承接。南向实体匾为四字“凤鸣山门”，字体转为可编辑的凸字网格。

平台侧补分段基础石，前坡裙是旧禁入范围内的一体岩座，连接原台基与山坡；未延伸到门前 Z=-3.05 的路线或东侧真实踏面。`H36_FIXED_035_STEPS_PLINTH` 保留 H.35 真实侧阶和门台网格，清除旧预受光颜色后只重分配 PBR 材质。CPU审计对比旧母版的顶点、拓扑和世界变换，完全一致。没有修改导航、碰撞或旧035资产。

材质语义名称为 `H36_Roof`、`H36_Wood`、`H36_Stone`、`H36_Plaque`，使用 Principled PBR、以粗糙度为主，没有预烘焙太阳颜色。新网格有可烘焙UV。源资产约9.77万三角（含旧精确踏面、四字凸字及独立瓦片）；这是烘焙母版，不代表已批准以同一复杂度在手机运行。运行时合批、烘焙和预算由主流程完成。

```sh
blender --background --factory-startup --python tools/build-gate-036.py
blender --background --factory-startup --python tools/check-gate-036-source.py
```

两条命令均只做CPU建模、导出或审计，不执行渲染。`first-source.json` 是当前结构和包络记录；`source-audit.json` 记录母版SHA、原阶精确保留、法线/非有限顶点检查及UV。第二稿审计零退化三角、零非有限顶点、零顶点颜色，无源相机或灯光。

字形来自本机 Noto Serif CJK Regular 字体集合；仅分发转换后的原创牌匾模型，不分发字体二进制。许可原文见 `OFL-Noto-CJK.txt`，字体SHA和生成说明见 `font-source.json`。

源模型生成成功和CPU审计不代表美术验收通过，也不代表iPhone或微信真机测试。原机位整屏图、连续操作与帧率由主任务统一验证。
