# H.30 分层迎客松

按用户批准的 `../pine-002/reference.png` 新制层图，不使用 H.29 模型截图。来源与 SHA256 见 `provenance.json`。图集 2172×724，三格分别为后冠、树干/贴地根、伸向石阶的前枝；透明 alpha。运行实现见 `../../sample/pine-layers.js`。

根部维持原世界坐标 (-7, groundAt(-7,-7), -7)，半径 .72 碰撞不变。三层分别使用真实世界深度及 cutout，人物可遮住树干、被前枝局部遮住、走出后恢复；不通过整树淡出来伪造。向镜头的上部微浮雕修正原白栏杆穿过干身，屏幕根点与剪影位置不变。整树不是整座山门的背景合成图，山门/台阶/地面仍是真实 3D 网格。

本轮专用于原固定斜俯视角，不承诺自由环绕视角。正常画幅遮挡量化与走位见 `../../evidence/h30/occlusion-final.json` 和样关实录。
